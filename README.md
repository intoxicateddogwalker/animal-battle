# Animal Battle — Lloyd's Card Game

The front door for the Animal Battle Telegram game: a Telegram Mini App page
hosted free on GitHub Pages.

- **Play:** https://t.me/Rantirealbot — the game plays in your Telegram chat
  with the bot. Lloyd plays the animal cards; you play the Biological Being.
- **This page:** the art, the rules, and the button that opens the bot.

The game itself — the real engine, Lloyd's picks, his notebook memory, the
clean +1 rewards, and the board pictures — lives in `lloydchrisisai/
telegram-card-game/` (the bot code), not in this repo. This repo holds only
the web page. Nothing here is scripted or faked: every match is played for
real, and Lloyd learns from every game.

## Rules in short

8 cards to start, draw 1 per turn. Play an animal, then each field animal
attacks once or holds back. Attacks deal ATK as damage; defenders don't hit
back. Lose 5 animals, lose the match. Traps (bear trap, pepper spray) sit
face-down, block an attack and kill the attacker. Remove-trap destroys a
face-down trap. Vets heal 4 HP after sitting one full round. Lloyd gets +1
when he wins, and +1 per post-match question right on the first try.
